# Ideia

Um aplicativo de lista de compras de supermercado voltado para o público 60+.

## Requisitos Não Funcionais

- Não pode ter login
- Não pode ter que configurar para começar a usar
- Interface de fácil utilização
- Letras grandes
- Usar terminologia do cotidiano e não da informática (por exemplo: ao invés de apagar a lista, jogar fora a lista; em vés de finalizar a compra, terminei)

## Requisitos

- Usar storage local
- Disponível primeiramente em Android e no futuro no iPhone
- Lista de produtos
- Adiciona produtos a lista através:
  - Selecionando um que o app sugere
  - Digitando
  - Falando
  - Pesquisando por nome
  - A inteligencia do app te propõe produtos baseado nos modelos matemáticos
- A lista é única para não gerar confusão
- Banco de icones para produtos
  - O app usa ícone para os produtos digitados (best match)
- Agrupar os items por categorias
  - Automaticamente
  - Manualmente
- Normalizar os nomes digitados/falados (por exemplo: maça = maçã = maças = maçãs)
- Notificações no celular para quando:
  - A lista está grande
  - Faz tempo que não compra algo
  - Ao passar perto de um mercado
- Partilhar a lista com outra pessoa
  - Precisa de cadastro (email)
  - Precisa de backend
- Histórico de compras
- Criar modelos matemáticos para encontrar padrões
  - Qual a frequencia que compra um determinado produto

## Comercialização

- Banners com anúncios
- Compra premium

## Layout

- Experiência mais próxima de uma lista em papel
- Deslizar o dedo por cima do produto para marcá-lo como comprado
- Depois de sair do mercado, tem um botão para Terminar a compra, onde vai limpar da lista o que comprou
- Botão para jogar a lista fora
